# Deferred work

- Hold-to-open/release-to-execute is implemented as opt-in `activation.behavior: "hold"`; Windows key-up suppression and interaction acceptance remain to be demonstrated.
- Opt-in virtual cursor, isolated feasibility experiment after desktop acceptance. Universal Raw Input game isolation is unsupported.
- REAPER scripting API integration and G502-specific setup/validation are deferred at the user's request. Existing application-specific keyboard-chord profiles remain available.
- Macro sequences, GUI editing, themes, plugins and updates are outside this MVP.
- Unicode-aware executable case folding and layout-aware OEM/punctuation key binding may be considered after a concrete need is demonstrated.
