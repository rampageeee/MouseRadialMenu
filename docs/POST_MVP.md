# Deferred work

- Hold-to-open/release-to-execute, only after reliable key-up suppression is demonstrated on Windows.
- Opt-in virtual cursor, isolated feasibility experiment after desktop acceptance. Universal Raw Input game isolation is unsupported.
- Macro sequences, GUI editing, themes, plugins and updates are outside this MVP.
- Unicode-aware executable case folding and layout-aware OEM/punctuation key binding may be considered after a concrete need is demonstrated.
